# POST `/api/contract/log`

Add a new log entry for a contract and update its current state accordingly.

## Request Body

| Field           | Type             | Required | Description                                                                 |
|-----------------|-----------------|---------|-----------------------------------------------------------------------------|
| `contractAddress` | `string`        | yes     | Smart contract address                                                      |
| `action`        | `string`        | yes     | Action performed (e.g., `"UPDATE_STATUS"`)                                  |
| `txHash`        | `string`        | yes     | Transaction hash associated with this log                                   |
| `account`       | `string`        | yes     | Wallet address performing the action                                        |
| `exporter`      | `string`        | yes     | Exporter involved in the contract                                           |
| `importer`      | `string`        | yes     | Importer involved in the contract                                           |
| `logistics`     | `array[string]` | no      | Array of logistics addresses or entities                                     |
| `insurance`     | `string`        | no      | Insurance entity involved                                                   |
| `inspector`     | `string`        | no      | Inspector entity involved                                                   |
| `requiredAmount`| `string`        | no      | Amount required for this step                                               |
| `extra`         | `object`        | no      | Additional contextual data                                                  |
| `timestamp`     | `number`        | yes     | Unix timestamp of the log entry                                             |
| `onChainInfo`   | `object`        | no      | Blockchain transaction info (`status`, `blockNumber`, `confirmations`)      |
| `verifyOnChain` | `boolean`       | no      | Whether to verify this action on-chain                                      |

### Example Request Body

```json
{
  "contractAddress": "0xContractAddress1",
  "action": "shipped",
  "txHash": "0xTxHash2",
  "account": "0xLogistics1",
  "exporter": "0xExporter1",
  "importer": "0xImporter1",
  "logistics": ["0xLogistics1"],
  "insurance": "0xInsurance1",
  "inspector": "0xInspector1",
  "requiredAmount": "1000",
  "extra": { "notes": "Goods shipped" },
  "timestamp": 1699995000,
  "onChainInfo": {
    "status": "success",
    "blockNumber": 123460,
    "confirmations": 8
  },
  "verifyOnChain": true
}
```

## Responses

### 201 — Created

Returned if the contract log is successfully created and the contract state is updated.

```json
{
  "success": true,
  "data": {
    "contractAddress": "0xContractAddress1",
    "action": "shipped",
    "txHash": "0xTxHash2",
    "account": "0xLogistics1",
    "exporter": "0xExporter1",
    "importer": "0xImporter1",
    "logistics": ["0xLogistics1"],
    "insurance": "0xInsurance1",
    "inspector": "0xInspector1",
    "requiredAmount": "1000",
    "extra": { "notes": "Goods shipped" },
    "timestamp": 1699995000,
    "onChainInfo": {
      "status": "success",
      "blockNumber": 123460,
      "confirmations": 8
    },
    "verifyOnChain": true
  }
}
```

### 400 — Bad Request

Returned if required fields are missing or invalid.

```json
{
  "success": false,
  "message": "Missing required fields: contractAddress, action, txHash, account"
}
```

### 401 — Unauthorized

Returned if the request does not include a valid Bearer token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error

Returned if the server fails to create the contract log.

```json
{
  "success": false,
  "message": "Failed to log contract action"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

