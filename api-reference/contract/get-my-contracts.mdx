# GET `/api/contract/my`

Fetch all smart contracts associated with the currently authenticated user.

## Responses

### 200 — OK

Returned if the list of contracts owned by the authenticated user is successfully fetched.

```json
{
  "success": true,
  "data": [
    {
      "contractAddress": "0xContractAddress1",
      "state": {
        "exporter": "0xExporter1",
        "importer": "0xImporter1",
        "logistics": ["0xLogistics1", "0xLogistics2"],
        "insurance": "0xInsurance1",
        "inspector": "0xInspector1",
        "status": "active",
        "currentStage": "shipping",
        "lastUpdated": 1699999999
      },
      "history": [
        {
          "action": "created",
          "txHash": "0xTxHash1",
          "account": "0xExporter1",
          "exporter": "0xExporter1",
          "importer": "0xImporter1",
          "logistics": ["0xLogistics1"],
          "insurance": "0xInsurance1",
          "inspector": "0xInspector1",
          "requiredAmount": "1000",
          "extra": { "notes": "Initial contract creation" },
          "timestamp": 1699990000,
          "onChainInfo": {
            "status": "success",
            "blockNumber": 123456,
            "confirmations": 12
          }
        }
      ]
    }
  ]
}
```

### 401 — Unauthorized

Returned if the request lacks a valid Bearer token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error

Returned if the server encounters an unexpected error while fetching the user’s contracts.

```json
{
  "success": false,
  "message": "Failed to fetch user contracts"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/contract/my" \
  -H "Authorization: Bearer <token>"
```
