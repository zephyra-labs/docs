# GET `/api/contract`

Fetch all deployed contracts in the system along with their current state and history.

## Query Parameters

This endpoint does not accept any query parameters.

## Responses

### 200 — OK

Returned if all deployed contracts are successfully fetched. Each contract includes its current state and full history.

```json
{
  "success": true,
  "data": [
    {
      "contractAddress": "0xContractAddress1",
      "state": {
        "exporter": "0xExporter1",
        "importer": "0xImporter1",
        "logistics": ["0xLogistics1", "0xLogistics2"],
        "insurance": "0xInsurance1",
        "inspector": "0xInspector1",
        "status": "active",
        "currentStage": "shipping",
        "lastUpdated": 1699999999
      },
      "history": [
        {
          "action": "created",
          "txHash": "0xTxHash1",
          "account": "0xExporter1",
          "exporter": "0xExporter1",
          "importer": "0xImporter1",
          "logistics": ["0xLogistics1"],
          "insurance": "0xInsurance1",
          "inspector": "0xInspector1",
          "requiredAmount": "1000",
          "extra": { "notes": "Initial contract creation" },
          "timestamp": 1699990000,
          "onChainInfo": {
            "status": "success",
            "blockNumber": 123456,
            "confirmations": 12
          }
        }
      ]
    }
  ]
}
```

### 401 — Unauthorized

Returned if the request does not include a valid Bearer token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error

Returned if the server fails to fetch the contracts.

```json
{
  "success": false,
  "message": "Failed to fetch deployed contracts"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/contract" \
  -H "Authorization: Bearer <token>"
```
