# GET `/api/contract/{address}/step`

Fetch the current lifecycle stage and status for a given contract address.

## Path Parameters

| Name      | Type     | Required | Description       |
|-----------|----------|----------|-----------------|
| `address` | `string` | yes      | Contract address |

## Responses

### 200 — OK

Returned if the current lifecycle step of the contract is successfully fetched.

```json
{
  "success": true,
  "data": {
    "exporter": "0xExporter1",
    "importer": "0xImporter1",
    "logistics": ["0xLogistics1", "0xLogistics2"],
    "insurance": "0xInsurance1",
    "inspector": "0xInspector1",
    "status": "active",
    "currentStage": "shipping",
    "lastUpdated": 1699999999
  }
}
```

### 400 — Bad Request

Returned if the `address` path parameter is missing or invalid.

```json
{
  "success": false,
  "message": "Contract address is required"
}
```

### 401 — Unauthorized

Returned if the request lacks a valid Bearer token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if no contract exists with the specified address.

```json
{
  "success": false,
  "message": "Contract not found"
}
```

### 500 — Server Error

Returned if the server encounters an unexpected error while fetching the current step.

```json
{
  "success": false,
  "message": "Failed to fetch contract step"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/contract/0xABC123/step" \
  -H "Authorization: Bearer <token>"
```
