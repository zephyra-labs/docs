# POST `/api/user/wallet-connect`

Connects a user's crypto wallet to the system.  
If the wallet address is not registered, a new user record will be automatically created.

## Request Body

### Content Type: `application/json`

```json
{
  "address": "0x123abc..."
}
```

| Field     | Type     | Required | Description                 |
| --------- | -------- | -------- | --------------------------- |
| `address` | `string` | yes        | Wallet address of the user. |

## Responses

### 201 — Created

User successfully connected or registered. Returns user data and JWT token.

```json
{
  "success": true,
  "data": {
    "address": "0x123abc...",
    "role": "user",
    "createdAt": 1699286400000,
    "lastLoginAt": 1699372800000,
    "metadata": {
      "name": "John Doe",
      "email": "john@example.com",
      "kycStatus": "pending"
    }
  },
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

### 400 — Bad Request

Returned if the wallet address is missing or invalid.

```json
{
  "success": false,
  "message": "Wallet connect failed: invalid address"
}
```

### 401 — Unauthorized

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Internal Server Error

```json
{
  "success": false,
  "message": "Internal server error"
}
```

## Authentication

No prior authentication required for wallet connect. A JWT token is returned upon success.

## Example Request

```bash
curl -X POST "https://api.zephyra.dev/api/user/wallet-connect" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "0x123abc..."
  }'
```
