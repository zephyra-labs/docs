# GET `/api/user`

Fetches all user profiles registered in the system.  
This endpoint is typically restricted to admin or system-level access.

## Headers

| Name | Type | Required | Description |
|------|------|-----------|-------------|
| `Authorization` | `string` | yes | Bearer token with admin or system privileges. |

## Responses

### 200 — OK

Returns a list of all users in the system.

```json
{
  "success": true,
  "data": [
    {
      "address": "0x123abc...",
      "role": "user",
      "createdAt": 1699286400000,
      "lastLoginAt": 1699372800000,
      "metadata": {
        "name": "John Doe",
        "email": "john@example.com",
        "kycStatus": "pending"
      }
    },
    {
      "address": "0x456def...",
      "role": "admin",
      "createdAt": 1699286500000,
      "lastLoginAt": 1699372900000,
      "metadata": {
        "name": "Alice Smith",
        "email": "alice@example.com",
        "kycStatus": "approved"
      }
    }
  ]
}
```

### 401 — Unauthorized

Returned if the JWT token is missing or invalid.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 403 — Forbidden

Returned if the authenticated user does not have permission to view all users.

```json
{
  "success": false,
  "message": "Forbidden"
}
```

### 500 — Internal Server Error

Returned if the server encounters an error while retrieving the user list.

```json
{
  "success": false,
  "message": "Failed to fetch users"
}
```

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/user" \
  -H "Authorization: Bearer <admin-jwt-token>"
```
