# DELETE `/api/kyc/{tokenId}`

Delete a KYC record permanently from the system by providing its token ID. Requires `action` and `executor` fields for logging.

## Path Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `tokenId` | string | yes | KYC token ID |

## Request Body

> Content-Type: `application/json`

| Name      | Type   | Required | Description |
|-----------|--------|----------|-------------|
| `action`  | string | yes      | Action performed for logging |
| `executor`| string | yes      | User performing the action |
| `txHash`  | string | no       | Optional transaction hash |

### Example Request Body

```json
{
  "action": "delete",
  "executor": "admin@example.com",
  "txHash": "0xabc123..."
}
```

## Responses

### 200 — OK

KYC record successfully deleted.

```json
{
  "message": "KYC deleted"
}
```

### 400 — Bad Request

Returned if required fields (`action` or `executor`) are missing.

```json
{
  "success": false,
  "message": "Missing action field"
}
```

```json
{
  "success": false,
  "message": "Missing executor field"
}
```

### 401 — Unauthorized

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

```json
{
  "success": false,
  "message": "KYC record not found"
}
```

### 422 — Unprocessable Entity

```json
{
  "success": false,
  "message": "Missing tokenId parameter"
}
```

### 500 — Server Error

```json
{
  "success": false,
  "message": "Failed to delete KYC"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X DELETE "https://api.zephyra.dev/api/kyc/kyc-uuid-123" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "delete",
    "executor": "admin@example.com",
    "txHash": "0xabc123..."
  }'
```

## Example Response

```json
{
  "message": "KYC deleted"
}
```
