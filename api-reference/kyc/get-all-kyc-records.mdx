# GET `/api/kyc`

Retrieve all KYC records in the system. No parameters are required. Requires authentication.

## Parameters

None.

## Responses

### 200 — OK

Returns a list of all KYC records.

```json
[
  {
    "tokenId": "kyc-uuid-123",
    "owner": "0x123abc...",
    "fileHash": "Qmabcdef...",
    "metadataUrl": "https://ipfs.io/ipfs/Qmabcdef...",
    "documentUrl": "https://storage.example.com/docs/kyc-123.pdf",
    "name": "NFT-123",
    "description": "KYC for user 0x123abc...",
    "txHash": "0xabc123...",
    "createdAt": 1699286400000,
    "updatedAt": 1699372800000,
    "status": "Pending"
  }
]
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error

Returned if there is a server error while fetching KYC records.

```json
{
  "success": false,
  "message": "Failed to fetch KYCs"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/kyc" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```
