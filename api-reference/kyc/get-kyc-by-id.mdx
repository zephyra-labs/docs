# GET `/api/kyc/{tokenId}`

Retrieve a KYC record by its token ID. Requires authentication.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `tokenId` | `string` | yes | KYC token ID (path parameter) |

## Responses

### 200 — OK

Returns the requested KYC record.

```json
{
  "tokenId": "kyc-uuid-123",
  "owner": "0x123abc...",
  "fileHash": "Qmabcdef...",
  "metadataUrl": "https://ipfs.io/ipfs/Qmabcdef...",
  "documentUrl": "https://storage.example.com/docs/kyc-123.pdf",
  "name": "NFT-123",
  "description": "KYC for user 0x123abc...",
  "txHash": "0xabc123...",
  "createdAt": 1699286400000,
  "updatedAt": 1699372800000,
  "status": "Pending"
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the KYC record with the specified token ID does not exist.

```json
{
  "success": false,
  "message": "KYC not found"
}
```

### 422 — Unprocessable Entity

Returned if the `tokenId` parameter is missing or invalid.

```json
{
  "success": false,
  "message": "Missing tokenId parameter"
}
```

### 500 — Server Error

Returned if there is a server error while fetching the KYC record.

```json
{
  "success": false,
  "message": "Failed to fetch KYC by ID"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/kyc/kyc-uuid-123" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```
