# GET `/api/kyc/{tokenId}/logs`

Retrieve the activity logs for a specific KYC record. Requires authentication.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `tokenId` | `string` | yes | KYC token ID (path parameter) |

## Responses

### 200 — OK

Returns a list of activity logs for the specified KYC record.

```json
[
  {
    "action": "Created",
    "executor": "admin@example.com",
    "timestamp": 1699286400000,
    "txHash": "0xabc123...",
    "remarks": "Initial KYC upload"
  },
  {
    "action": "Reviewed",
    "executor": "admin@example.com",
    "timestamp": 1699372800000,
    "txHash": "0xdef456...",
    "remarks": "Verified documents"
  }
]
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if no logs are found for the given KYC token.

```json
{
  "success": false,
  "message": "No logs found"
}
```

### 422 — Unprocessable Entity

Returned if the `tokenId` parameter is missing.

```json
{
  "success": false,
  "message": "Missing tokenId parameter"
}
```

### 500 — Server Error

Returned if there is a server error while fetching KYC logs.

```json
{
  "success": false,
  "message": "Failed to fetch KYC logs"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/kyc/kyc-uuid-123/logs" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```
