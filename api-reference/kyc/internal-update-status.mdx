# PATCH `/api/kyc/internal/{tokenId}/status`

Perform an **internal update** of a KYC record's status.  
Only accessible by **administrative or system-level accounts**.

## Path Parameters

| Name      | Type   | Required | Description |
|-----------|--------|----------|-------------|
| `tokenId` | string | yes      | KYC token ID |

## Request Body

Update the status and optionally provide audit information.

| Field       | Type   | Required | Description |
|------------ |-------|----------|-------------|
| `status`    | string | yes      | New KYC status (`Draft`, `Reviewed`, `Signed`, `Revoked`) |
| `reviewedBy`| string | no       | Internal reviewer name/email |
| `signature` | string | no       | Optional signature hash |
| `txHash`    | string | no       | Optional transaction hash |
| `remarks`   | string | no       | Optional notes or remarks |

### Example Request Body

```json
{
  "status": "Reviewed",
  "reviewedBy": "admin@example.com",
  "signature": "0xSignatureHash",
  "txHash": "0xTransactionHash",
  "remarks": "Verified and approved"
}
```

## Responses

### 200 — OK

Returns the updated KYC record.

```json
{
  "tokenId": "kyc-uuid-123",
  "owner": "0x123abc...",
  "fileHash": "Qmabcdef...",
  "metadataUrl": "https://ipfs.io/ipfs/Qmabcdef...",
  "documentUrl": "https://storage.example.com/docs/kyc-123.pdf",
  "name": "NFT-123",
  "description": "KYC for user 0x123abc...",
  "txHash": "0xabc123...",
  "status": "Reviewed",
  "reviewedBy": "admin@example.com",
  "signature": "0xSignatureHash",
  "remarks": "Verified and approved",
  "createdAt": 1699286400000,
  "updatedAt": 1699372800000
}
```

### 400 — Bad Request

Returned if the request body is invalid or missing required fields.

```json
{
  "success": false,
  "message": "Missing status field"
}
```

### 401 — Unauthorized

Returned if the internal bearer token is missing or invalid.

```json
{
  "success": false,
  "message": "Internal authentication failed"
}
```

### 404 — Not Found

Returned if the KYC record does not exist.

```json
{
  "success": false,
  "message": "KYC record not found"
}
```

### 422 — Unprocessable Entity

Returned if the path parameter is invalid or missing.

```json
{
  "success": false,
  "message": "Missing tokenId parameter"
}
```

### 500 — Server Error

Returned if the update operation fails on the server.

```json
{
  "success": false,
  "message": "Failed to update KYC status"
}
```

## Authentication

This endpoint requires **Admin privileges** and a valid **Bearer Token**.

## Example Request

```bash
curl -X PATCH "https://api.zephyra.dev/api/kyc/internal/kyc-uuid-123/status" \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "Reviewed",
    "reviewedBy": "admin@example.com",
    "signature": "0xSignatureHash",
    "txHash": "0xTransactionHash",
    "remarks": "Verified and approved"
  }'
```
