# GET `/api/kyc/owner/{owner}`

Get all KYC records for a specific owner. Requires authentication.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `owner` | `string` | yes | Owner wallet address (path parameter) |

## Responses

### 200 — OK

Returns a list of KYC records for the specified owner.

```json

  {
    "tokenId": "kyc-uuid-123",
    "owner": "0x123abc...",
    "fileHash": "Qmabcdef...",
    "metadataUrl": "https://ipfs.io/ipfs/Qmabcdef...",
    "documentUrl": "https://storage.example.com/docs/kyc-123.pdf",
    "name": "NFT-123",
    "description": "KYC for user 0x123abc...",
    "txHash": "0xabc123...",
    "createdAt": 1699286400000,
    "updatedAt": 1699372800000,
    "status": "Pending"
  },
  {
    "tokenId": "kyc-uuid-124",
    "owner": "0x123abc...",
    "fileHash": "Qmghijkl...",
    "metadataUrl": "https://ipfs.io/ipfs/Qmghijkl...",
    "documentUrl": "https://storage.example.com/docs/kyc-124.pdf",
    "name": "NFT-124",
    "description": "KYC for user 0x123abc...",
    "txHash": "0xdef456...",
    "status": "Reviewed",
    "createdAt": 1699386400000,
    "updatedAt": 1699472800000
  }
]
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if no KYC records are found for the specified owner.

```json
{
  "success": false,
  "message": "No KYC records found for owner"
}
```

### 422 — Unprocessable Entity

Returned if the `owner` parameter is missing.

```json
{
  "success": false,
  "message": "Missing owner parameter"
}
```

### 500 — Server Error

Returned if there is a server error while fetching KYC records for the owner.

```json
{
  "success": false,
  "message": "Failed to fetch KYCs for owner"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/kyc/owner/0x123abc..." \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```
