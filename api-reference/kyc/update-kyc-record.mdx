# PATCH `/api/kyc/{tokenId}`

Update an existing KYC record including its status, name, description, and metadata. Requires `action` and `executor` fields for logging.

## Path Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `tokenId` | string | yes | KYC token ID |

## Request Body

> Content-Type: `application/json`

| Name         | Type   | Required | Description |
|--------------|--------|----------|-------------|
| `owner`      | string | no       | Wallet address of the KYC owner |
| `fileHash`   | string | no       | IPFS hash of the KYC file |
| `metadataUrl`| string | no       | URL pointing to KYC metadata JSON |
| `name`       | string | no       | Optional name for the KYC |
| `description`| string | no       | Optional description |
| `status`     | string | no       | Status of KYC; one of `"Draft","Reviewed","Signed","Revoked"` |
| `action`     | string | yes      | Action performed for logging |
| `executor`   | string | yes      | User performing the action |
| `txHash`     | string | no       | Optional transaction hash |

### Example Request Body

```json
{
  "owner": "0x123abc...",
  "fileHash": "Qmabcdef...",
  "metadataUrl": "https://ipfs.io/ipfs/Qmabcdef...",
  "name": "NFT-123",
  "description": "Updated KYC info",
  "status": "Reviewed",
  "action": "update",
  "executor": "admin@example.com",
  "txHash": "0xabc123..."
}
```

## Responses

### 200 — OK

Returns the updated KYC record.

```json
{
  "tokenId": "kyc-uuid-123",
  "owner": "0x123abc...",
  "fileHash": "Qmabcdef...",
  "metadataUrl": "https://ipfs.io/ipfs/Qmabcdef...",
  "documentUrl": "https://storage.example.com/docs/kyc-123.pdf",
  "name": "NFT-123",
  "description": "Updated KYC info",
  "txHash": "0xabc123...",
  "status": "Reviewed",
  "createdAt": 1699286400000,
  "updatedAt": 1699372800000
}
```

### 400 — Bad Request

Returned if required fields (`action` or `executor`) are missing.

```json
{
  "success": false,
  "message": "Missing action field"
}
```

```json
{
  "success": false,
  "message": "Missing executor field"
}
```

### 401 — Unauthorized

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

```json
{
  "success": false,
  "message": "KYC not found"
}
```

### 422 — Unprocessable Entity

```json
{
  "success": false,
  "message": "Missing tokenId parameter"
}
```

### 500 — Server Error

```json
{
  "success": false,
  "message": "Failed to update KYC"
}
```

## Authentication

This endpoint requires a **Bearer Token**.
