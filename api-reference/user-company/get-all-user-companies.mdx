# GET `/api/user-company`

Fetch all user-company associations with optional pagination, search, and filters.

## Query Parameters

| Name | Type | Required | Description |
|------|------|-----------|-------------|
| `page` | `integer` | no | Page number (default: 1) |
| `limit` | `integer` | no | Number of records per page (default: 10) |
| `search` | `string` | no | Search string to filter by `userAddress` or `companyId` |
| `role` | `string` | no | Filter by user role (`owner`, `admin`, `manager`, `staff`, `viewer`) |
| `status` | `string` | no | Filter by status (`pending`, `active`, `rejected`) |
| `companyId` | `string` | no | Filter by company ID |

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/user-company?page=1&limit=10&search=staff&role=owner&status=pending&companyId=company_01" \
  -H "Authorization: Bearer <token>"
```
