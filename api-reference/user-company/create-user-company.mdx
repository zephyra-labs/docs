# POST `/api/user-company`

Create a new user-company record by linking a user wallet to a company.

## Request Body

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `userAddress` | `string` | yes | Wallet address of the user |
| `companyId` | `string` | yes | Identifier of the company |
| `role` | `string` | yes | Role of the user in the company (`owner`, `admin`, `manager`, `staff`, `viewer`) |
| `status` | `string` | yes | Status of the association (`pending`, `active`, `rejected`) |
| `txHash` | `string` | no | Transaction hash if the action is recorded on-chain |
| `joinedAt` | `number` | yes | Timestamp when the user joined the company |
| `onchainJoinedAt` | `number` | no | Timestamp when the association was recorded on-chain |

> Content-Type: `application/json`

### Example Request Body

```json
{
  "userAddress": "0x123abc...",
  "companyId": "company_01",
  "role": "staff",
  "status": "pending",
  "txHash": "0xabc123...",
  "joinedAt": 1699286400000,
  "onchainJoinedAt": 1699286500000
}
```

```json
    "companyId": "company_01",
    "role": "staff",

    "joinedAt": 1699286400000,
    "updatedAt": 1699286400000,
    "txHash": "0xabc123...",
    "onchainJoinedAt": 1699286500000
  }
}
```

### 400 — Bad Request

Returned when validation fails or required fields are missing.

```json
{
  "success": false,
  "message": "Invalid request body"
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error

Returned if there is a server-side error while creating the user-company record.

```json

  "message": "Failed to create user-company relation"

```

This endpoint requires a **Bearer Token**.
