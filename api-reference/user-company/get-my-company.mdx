# GET `/api/user-company/my-company`

Fetch the company profile of the currently authenticated user.  
This endpoint allows any logged-in user to view the company record they are currently associated with.

## Responses

### 200 — OK

Returns the company profile of the current user.

```json
{
  "success": true,
  "data": {
    "id": "company_01",
    "name": "Example Company",
    "address": "123 Blockchain St.",
    "website": "https://example.com",
    "status": "active",
    "createdAt": 1699286400000,
    "updatedAt": 1699372800000
  }
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the current user does not have an associated company.

```json
{
  "success": false,
  "message": "No company relation found"
}
```

Or if the company record does not exist:

```json
{
  "success": false,
  "message": "Company not found"
}
```

### 500 — Server Error

Returned if there is a server-side error while fetching the company profile.

```json
{
  "success": false,
  "message": "Failed to fetch user's company"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/user-company/my-company" \
  -H "Authorization: Bearer <token>"
```
