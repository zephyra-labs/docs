# PUT `/api/user-company/my-company`

Update the company profile of the currently authenticated user.  
This endpoint allows authenticated users to modify their own company relationship data such as role, status, or transaction metadata.

## Request Body

| Name | Type | Required | Description |
|------|------|-----------|-------------|
| `role` | `string` | no | Role of the user in the company (`owner`, `admin`, `manager`, `staff`, `viewer`) |
| `status` | `string` | no | Status of the company association (`pending`, `active`, `rejected`) |
| `txHash` | `string` | no | Transaction hash for on-chain record updates |
| `updatedAt` | `number` | no | Timestamp (ms) of the update |
| `onchainJoinedAt` | `number` | no | Timestamp (ms) when joined on-chain |

> Content-Type: `application/json`

### Example Request Body

```json
{
  "role": "owner",
  "status": "pending",
  "txHash": "0xabc123...",
  "updatedAt": 1699372800000,
  "onchainJoinedAt": 1699286400000
}
```

## Responses

### 200 — OK

Company profile successfully updated.

```json
{
  "success": true,
  "data": {
    "id": "user_company_01",
    "userAddress": "0x123abc...",
    "companyId": "company_01",
    "role": "owner",
    "status": "pending",
    "joinedAt": 1699286400000,
    "updatedAt": 1699372800000,
    "txHash": "0xabc123...",
    "onchainJoinedAt": 1699286400000
  }
}
```

### 400 — Bad Request

```json
{
  "success": false,
  "message": "Invalid input data"
}
```

### 401 — Unauthorized

```json
{
  "success": false,
  "message": "Unauthorized"
}
```

### 403 — Forbidden

```json
{
  "success": false,
  "message": "Only company owner can update company data"
}
```

### 404 — Not Found

User relation or company not found.

```json
{
  "success": false,
  "message": "User is not linked to any company"
}
```

Or if the company record itself is missing:

```json
{
  "success": false,
  "message": "Company not found"
}
```

### 500 — Server Error

```json
{
  "success": false,
  "message": "Failed to update company"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X PUT "https://api.zephyra.dev/api/user-company/my-company" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "role": "owner",
    "status": "pending",
    "txHash": "0xabc123...",
    "updatedAt": 1699372800000,
    "onchainJoinedAt": 1699286400000
  }'
```
