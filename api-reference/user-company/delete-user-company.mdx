# DELETE `/api/user-company/{id}`

Permanently delete a user-company record identified by its ID. Only administrators can perform this action.

## Path Parameters

| Name | Type | Required | Description |
|------|------|-----------|-------------|
| `id` | `string` | yes | Unique identifier of the user-company record |

## Responses

### 200 — OK

User-company record successfully deleted.

```json
{
  "success": true,
  "data": {
    "message": "Relation deleted successfully"
  }
}
```

### 400 — Bad Request

```json
{
  "success": false,
  "message": "Failed to delete relation"
}
```

### 401 — Unauthorized

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 403 — Forbidden

```json
{
  "success": false,
  "message": "Access denied. Admins only."
}
```

### 404 — Not Found

```json
{
  "success": false,
  "message": "Relation not found"
}
```

### 422 — Unprocessable Entity

```json
{
  "success": false,
  "message": "Missing id parameter"
}
```

### 500 — Server Error

```json
{
  "success": false,
  "message": "Failed to delete relation"
}
```

## Authentication

This endpoint requires a **Bearer Token** and admin privileges.

## Example Request

```bash
curl -X DELETE "https://api.zephyra.dev/api/user-company/uc-uuid-123" \
  -H "Authorization: Bearer <token>"
```

## Example Response

```json
{
  "success": true,
  "data": {
    "message": "Relation deleted successfully"
  }
}
```
