# GET `/api/user-company/user/{address}`

Fetch all user-company records associated with a specific user wallet address.

## Path Parameters

| Name | Type | Required | Description |
|------|------|-----------|-------------|
| `address` | `string` | yes | Wallet address of the user |

## Responses

### 200 — OK

Returns a list of user-company records for the specified user.

```json
{
  "success": true,
  "data": [
    {
      "id": "uc-uuid-123",
      "userAddress": "0x123abc...",
      "companyId": "company_01",
      "role": "admin",
      "status": "active",
      "joinedAt": 1699286400000,
      "updatedAt": 1699372800000,
      "txHash": "0xabc123...",
      "onchainJoinedAt": 1699286500000
    },
    {
      "id": "uc-uuid-124",
      "userAddress": "0x123abc...",
      "companyId": "company_02",
      "role": "staff",
      "status": "pending",
      "joinedAt": 1699286600000,
      "updatedAt": 1699372900000,
      "txHash": "0xdef456...",
      "onchainJoinedAt": 1699286700000
    }
  ]
}
```

### 401 — Unauthorized

Returned if the request is missing or contains an invalid authentication token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if no user-company records are found for the given address.

```json
{
  "success": false,
  "message": "No relations found for user"
}
```

### 422 — Validation Error

Returned if the `address` parameter is missing.

```json
{
  "success": false,
  "message": "Missing user address"
}
```

### 500 — Server Error

Returned if there is a server-side error while fetching the records.

```json
{
  "success": false,
  "message": "Failed to fetch user relations"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/user-company/user/0x123abc..." \
  -H "Authorization: Bearer <token>"
```
