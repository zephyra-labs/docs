# GET `/api/user-company/{id}`

Fetch a single user-company record using its unique identifier.

## Path Parameters

| Name | Type | Required | Description |
|------|------|-----------|-------------|
| `id` | `string` | yes | Unique identifier of the user-company record |

## Responses

### 200 — OK

Returns the user-company record with the specified ID.

```json
{
  "success": true,
  "data": {
    "id": "uc-uuid-123",
    "userAddress": "0x123abc...",
    "companyId": "company_01",
    "role": "staff",
    "status": "active",
    "joinedAt": 1699286400000,
    "updatedAt": 1699372800000,
    "txHash": "0xabc123...",
    "onchainJoinedAt": 1699286500000
  }
}
```

### 400 — Bad Request

```json
{
  "success": false,
  "message": "Invalid record ID"
}
```

### 401 — Unauthorized

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

```json
{
  "success": false,
  "message": "Relation not found"
}
```

### 422 — Unprocessable Entity

```json
{
  "success": false,
  "message": "Missing id parameter"
}
```

### 500 — Server Error

```json
{
  "success": false,
  "message": "Failed to fetch relation"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/user-company/uc-uuid-123" \
  -H "Authorization: Bearer <token>"
```
