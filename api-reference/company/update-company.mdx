# PUT `/api/company/{id}`

Update a company's information. This endpoint is restricted to admin users.

## Path Parameters

| Name | Type   | Required | Description |
|------|--------|----------|-------------|
| `id` | `string` | yes      | Company ID  |

## Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | `string` | no | Company unique identifier |
| `name` | `string` | yes | Name of the company |
| `address` | `string` | yes | Street address |
| `city` | `string` | yes | City |
| `stateOrProvince` | `string` | yes | State or province |
| `postalCode` | `string` | yes | Postal code |
| `country` | `string` | yes | Country |
| `email` | `string` | no | Contact email |
| `phone` | `string` | no | Contact phone number |
| `taxId` | `string` | no | Tax ID |
| `registrationNumber` | `string` | no | Business registration number |
| `businessType` | `string` | no | Type of business |
| `website` | `string` | no | Website URL |
| `walletAddress` | `string` | no | Associated wallet address |
| `verified` | `boolean` | no | Verification status |
| `createdAt` | `number` | no | Timestamp of creation |
| `updatedAt` | `number` | no | Timestamp of last update |
| `executor` | `string` | yes | Admin wallet performing the update |

### Example

```json
{
  "name": "Zephyra Labs",
  "address": "123 Blockchain St",
  "city": "Bangkok",
  "stateOrProvince": "Bangkok",
  "postalCode": "10110",
  "country": "Thailand",
  "email": "contact@zephyra.dev",
  "phone": "+66 1234 5678",
  "walletAddress": "0xABC123...",
  "verified": true,
  "executor": "0xAdminWallet..."
}
```

## Responses

### 200 — OK

Returned if the company is successfully updated.

```json
{
  "success": true,
  "data": {
    "id": "company-123",
    "name": "Zephyra Labs",
    "address": "123 Blockchain St",
    "city": "Bangkok",
    "stateOrProvince": "Bangkok",
    "postalCode": "10110",
    "country": "Thailand",
    "email": "contact@zephyra.dev",
    "phone": "+66 1234 5678",
    "taxId": "string",
    "registrationNumber": "string",
    "businessType": "string",
    "website": "string",
    "walletAddress": "0xABC123...",
    "verified": true,
    "createdAt": 0,
    "updatedAt": 0
  }
}
```

### 400 — Bad Request

Returned if required fields (`id` or `executor`) are missing.

```json
{
  "success": false,
  "message": "Executor is required"
}
```

```json
{
  "success": false,
  "message": "Company ID is required"
}
```

### 401 — Unauthorized

Returned if the request does not include a valid Bearer token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if no company exists with the given ID.

```json
{
  "success": false,
  "message": "Company not found"
}
```

### 422 — Unprocessable Entity

Returned if fields fail validation (e.g., `name` not a string).

```json
{
  "success": false,
  "message": "Company name must be a string"
}
```

### 500 — Server Error

Returned if the server fails to update the company.

```json
{
  "success": false,
  "message": "Failed to update company"
}
```

## Authentication

This endpoint requires an **Admin Bearer Token**.

## Example Request (cURL)

```bash

  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \

    "name": "Zephyra Labs",
```
