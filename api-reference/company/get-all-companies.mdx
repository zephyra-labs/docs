# GET `/api/company`

Fetch all companies registered in the system.  
No parameters are required.

### 401 — Unauthorized

Returned if the request does not include a valid Bearer token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error

Returned if the server fails to fetch the companies.

```json
{
  "success": false,
  "message": "Failed to fetch companies"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request (cURL)

```bash
curl -X GET "https://api.zephyra.dev/api/company" \
  -H "Authorization: Bearer <token>"
```
