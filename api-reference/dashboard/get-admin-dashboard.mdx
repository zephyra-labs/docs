# GET `/api/dashboard/admin`

Fetch system-wide metrics and recent activities for the admin dashboard.  
Accessible by admin users only.

### 400 — Bad Request

Returned if the request format is invalid.

```json
{
  "success": false,
  "message": "Invalid request format"
}
```

### 401 — Unauthorized

Returned if the request lacks a valid Bearer token or admin privileges.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the dashboard data cannot be found.

```json
{
  "success": false,
  "message": "Dashboard data not found"
}
```

### 422 — Validation Failed

Returned if any query parameters fail validation (e.g., `limit` is not a number).

```json
{
  "success": false,
  "message": "Limit must be a number"
}
```

### 500 — Server Error

Returned if the server encounters an unexpected error while fetching the dashboard data.

```json
{
  "success": false,
  "message": "Failed to fetch admin dashboard"
}
```

## Authentication

This endpoint requires a **Bearer Token** with admin privileges.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/dashboard/admin" \
  -H "Authorization: Bearer <admin-token>"
```
