# GET `/api/wallet/{account}/logs`

Fetch all wallet log entries for a given wallet account.

## Path Parameters

| Name | Type | Required | Description |
|------|------|-----------|-------------|
| `account` | `string` | yes | Wallet address of the user |

## Responses

### 200 — OK

Returns a list of wallet log records for the specified account.

```json
{
  "success": true,
  "data": [
    {
      "account": "0x123abc...",
      "action": "connect",
      "timestamp": 1699286400000,
      "meta": {
        "ip": "192.168.1.1",
        "device": "Chrome on Windows"
      }
    },
    {
      "account": "0x123abc...",
      "action": "disconnect",
      "timestamp": 1699372800000,
      "meta": {
        "ip": "192.168.1.1",
        "device": "Chrome on Windows"
      }
    }
  ]
}
```

### 401 — Unauthorized

Returned if the request is missing or contains an invalid authentication token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if no wallet logs are found for the given account.

```json
{
  "success": false,
  "message": "Wallet logs not found"
}
```

### 500 — Server Error

```json
{
  "success": false,
  "message": "Failed to fetch wallet logs for account"
}
```

## Authentication

This endpoint requires a **Bearer Token** for authentication.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/wallet/0x123abc/logs" \
  -H "Authorization: Bearer <token>"
```
