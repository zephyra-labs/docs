# GET `/api/wallet/logs`

Fetch all wallet log entries, including login and disconnect events. Only administrators can access this endpoint.

## Responses

### 200 — OK

Returns a list of wallet log records.

```json
{
  "success": true,
  "data": [
    {
      "account": "0x123abc...",
      "action": "connect",
      "timestamp": 1699286400000,
      "meta": {
        "ip": "192.168.1.1",
        "device": "Chrome on Windows"
      }
    },
    {
      "account": "0x456def...",
      "action": "disconnect",
      "timestamp": 1699372800000,
      "meta": {
        "ip": "192.168.1.2",
        "device": "MetaMask Mobile"
      }
    }
  ]
}
```

### 401 — Unauthorized

Returned if the request is missing or contains an invalid authentication token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error

```json
{
  "success": false,
  "message": "Failed to fetch wallet logs"
}
```

## Authentication

This endpoint requires a **Bearer Token** for authentication (admin only).

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/wallet/logs" \
  -H "Authorization: Bearer <token>"
```
