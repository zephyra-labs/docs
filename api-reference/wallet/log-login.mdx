# POST `/api/wallet/log-login`

Record a wallet login event for a specific user account.

## Request Body

| Name | Type | Required | Description |
|------|------|-----------|-------------|
| `account` | `string` | yes | Wallet address of the user |
| `action` | `string` | yes | Action performed (`connect`, `disconnect`, `switchNetwork`, `signMessage`) |
| `timestamp` | `number` | yes | Unix timestamp of the login event |
| `meta` | `object` | no | Optional metadata (IP, device info, session ID) |

> Content-Type: `application/json`

### Example Request Body

```json
{
  "account": "0x123abc...",
  "action": "connect",
  "timestamp": 1699286400000,
  "meta": {
    "ip": "192.168.1.1",
    "device": "Chrome on Windows"
  }
}
```

## Responses

### 201 — Created

Wallet login log successfully created.

```json
{
  "success": true,
  "data": {
    "account": "0x123abc...",
    "action": "connect",
    "timestamp": 1699286400000,
    "meta": {
      "ip": "192.168.1.1",
      "device": "Chrome on Windows"
    }
  }
}
```

### 400 — Bad Request

Returned when the request body contains invalid or missing fields.

```json
{
  "success": false,
  "message": "Account parameter is required"
}
```

### 401 — Unauthorized

Returned if the request is missing or contains an invalid authentication token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error

```json
{
  "success": false,
  "message": "Failed to log wallet login"
}
```

## Authentication

This endpoint requires a **Bearer Token** for authentication.

## Example Request

```bash
curl -X POST "https://api.zephyra.dev/api/wallet/log-login" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "account": "0x123abc...",
    "action": "connect",
    "timestamp": 1699286400000,
    "meta": {
      "ip": "192.168.1.1",

    }
  }'
```
