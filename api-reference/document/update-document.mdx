# PATCH `/api/document/{tokenId}`

Update a document’s information such as name, description, status, or linked contracts.

## Path Parameters

| Name      | Type    | Required | Description       |
|-----------|---------|----------|-----------------|
| `tokenId` | integer | yes      | Document token ID |

## Request Body

Provide a JSON object containing the updated fields.

```json
{
  "owner": "0x123abc...",
  "name": "Invoice #123 Updated",
  "description": "Updated invoice description",
  "docType": "Invoice",
  "action": "Updated",
  "account": "0xSigner1",
  "txHash": "0xTransactionHash1"
}
```

> Only fields you include in the body will be updated. Unspecified fields will remain unchanged.

## Responses

### 200 — OK

Returns the updated document object.

```json
{
  "success": true,
  "data": {
    "tokenId": 123,
    "owner": "0x123abc...",
    "fileHash": "Qmabcdef...",
    "uri": "https://storage.example.com/docs/doc-123.pdf",
    "docType": "Invoice",
    "linkedContracts": ["0xcontract1"],
    "status": "Reviewed",
    "signer": "0xSigner1",
    "createdAt": 1699286400000,
    "updatedAt": 1699372800000,
    "name": "Invoice #123 Updated",
    "description": "Updated invoice description",
    "metadataUrl": "https://metadata.example.com/doc-123.json"
  }
}
```

### 401 — Unauthorized

Returned if the request lacks a valid Bearer token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if no document exists with the given tokenId.

```json
{
  "success": false,
  "message": "Document not found"
}
```

### 422 — Unprocessable Entity

Returned if the tokenId format is invalid.

```json
{
  "success": false,
  "message": "Invalid tokenId format"
}
```

Returned if required action fields are missing.

```json
{
  "success": false,
  "message": "Missing action field"
}
```

Returned if required account fields are missing.

```json
{
  "success": false,
  "message": "Missing account field"
}
```

### 500 — Server Error

Returned if the server encounters an unexpected error while updating the document.

```json
{
  "success": false,
  "message": "Failed to update document"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X PATCH "https://api.zephyra.dev/api/document/123" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "status": "Approved",
    "description": "Updated invoice after review"
  }'
```
