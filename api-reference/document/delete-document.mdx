# DELETE `/api/document/{tokenId}`

Delete a document permanently from the system by providing its token ID.

## Path Parameters

| Name      | Type    | Required | Description       |
|-----------|---------|----------|-----------------|
| `tokenId` | integer | yes      | Document token ID |

## Request Body

Provide a JSON object for logging purposes:

```json
{
  "action": "Deleted",
  "account": "0xSigner1",
  "txHash": "0xTransactionHash1"
}
```

## Responses

### 200 — OK

Returns a confirmation message after successful deletion.

```json
{
  "success": true,
  "data": {
    "message": "Document deleted successfully"
  }
}
```

### 401 — Unauthorized

Returned if the request lacks a valid Bearer token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the document with the specified token ID does not exist.

```json
{
  "success": false,
  "message": "Document not found"
}
```

### 422 — Unprocessable Entity

Returned if required action fields are missing.

```json
{
  "success": false,
  "message": "Missing action field"
}
```

Returned if required account fields are missing.

```json
{
  "success": false,
  "message": "Missing account field"
}
```

Returned if the token ID format is invalid.

```json
{
  "success": false,
  "message": "Invalid tokenId format"
}
```

### 500 — Server Error

Returned if the server encounters an unexpected error while deleting the document.

```json
{
  "success": false,
  "message": "Failed to delete document"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X DELETE "https://api.zephyra.dev/api/document/123" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "action": "Deleted",
    "account": "0xSigner1",
    "txHash": "0xTransactionHash1"
  }'
```

## Example Response

```json
{
  "success": true,
  "data": {
    "message": "Document deleted successfully"
  }
}
```
