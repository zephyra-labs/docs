# GET `/api/document/{tokenId}/logs`

Fetch all recorded activity logs related to a specific document identified by its token ID.

## Path Parameters

| Name      | Type    | Required | Description       |
|-----------|---------|----------|-----------------|
| `tokenId` | integer | yes      | Document token ID |

## Responses

### 200 — OK

Returns a list of activity logs related to the document.

```json
[
  {
    "action": "Created",
    "account": "0xSigner1",
    "timestamp": 1700000000000,
    "txHash": "0xTransactionHash1"
  },
  {
    "action": "Updated",
    "account": "0xSigner2",
    "timestamp": 1700003600000,
    "txHash": "0xTransactionHash2"
  }
]
```

### 400 — Bad Request

Returned if the request is malformed.

```json
{
  "success": false,
  "message": "Bad request"
}
```

### 401 — Unauthorized

Returned if the request lacks a valid Bearer token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the document does not exist.

```json
{
  "success": false,
  "message": "Document not found"
}
```

Returned if the document has no logs.

```json
{
  "success": false,
  "message": "No logs found"
}
```

### 422 — Unprocessable Entity

Returned if the `tokenId` format is invalid (e.g., not an integer).

```json
{
  "success": false,
  "message": "Invalid tokenId format"
}
```

### 500 — Server Error

Returned if the server encounters an unexpected error while fetching the logs.

```json
{
  "success": false,
  "message": "Failed to fetch document logs"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/document/123/logs" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```
