# POST `/api/document/contract/{addr}/docs`

Attach a new document to a given contract.

## Path Parameters

| Name | Type   | Required | Description        |
|------|--------|----------|------------------|
| `addr` | `string` | yes      | Contract address  |

## Request Body

| Field | Type | Required | Description |
|-------|------|----------|------------|
| `tokenId` | `number` | yes | Unique token ID of the document |
| `owner` | `string` | yes | Wallet address of the document owner |
| `fileHash` | `string` | yes | IPFS file hash of the document |
| `uri` | `string` | yes | URL to access the document |
| `docType` | `string` | yes | Type of document (Invoice, B/L, COO, PackingList, Other) |
| `linkedContracts` | `array[string]` | no | List of related contract addresses |
| `status` | `string` | yes | Current status of the document (Draft, Reviewed, Signed, Revoked) |
| `signer` | `string` | yes | Wallet address of signer |
| `createdAt` | `number` | yes | Timestamp of creation |
| `updatedAt` | `number` | yes | Timestamp of last update |
| `name` | `string` | yes | Name/title of the document |
| `description` | `string` | no | Description of the document |
| `metadataUrl` | `string` | no | URL for document metadata |
| `action` | `string` | yes | Action triggering this document creation (e.g., "uploaded") |
| `txHash` | `string` | yes | Blockchain transaction hash related to this document |

### Example Request Body

```json
{
  "tokenId": 123,
  "owner": "0xOwner1",
  "fileHash": "Qmabcdef...",
  "uri": "https://storage.example.com/docs/doc-123.pdf",
  "docType": "Invoice",
  "linkedContracts": ["0xContractAddress1"],
  "status": "Draft",
  "signer": "0xSigner1",
  "createdAt": 1700000000000,
  "updatedAt": 1700000000000,
  "name": "Invoice #123",
  "description": "Invoice for trade #456",
  "metadataUrl": "https://metadata.example.com/doc-123.json",
  "action": "uploaded",
  "txHash": "0xTxHash1"
}
```

## Responses

### 201 — Created

Document successfully created and attached to the contract.

```json
{
  "tokenId": 123,
  "owner": "0xOwner1",
  "fileHash": "Qmabcdef...",
  "uri": "https://storage.example.com/docs/doc-123.pdf",
  "docType": "Invoice",
  "linkedContracts": ["0xContractAddress1"],
  "signer": "0xSigner1",
  "status": "Draft",
  "createdAt": 1700000000000,
  "updatedAt": 1700000000000,
  "name": "Invoice #123",
  "description": "Invoice for trade #456",
  "metadataUrl": "https://metadata.example.com/doc-123.json"
}
```

### 400 — Bad Request

Returned if the request body format is invalid.

```json
{
  "success": false,
  "message": "Invalid request body format"
}
```

### 401 — Unauthorized

Returned if the request lacks a valid Bearer token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 422 — Unprocessable Entity

Returned if a required field is missing or invalid.

```json
{
  "success": false,
  "message": "Missing required field: tokenId"
}
```

### 404 — Not Found

Returned if the specified contract cannot be found.

```json
{
  "success": false,
  "message": "Contract not found"
}
```

### 500 — Server Error

Returned if the server encounters an unexpected error while attaching the document.

```json
{
  "success": false,
  "message": "Failed to attach document"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X POST "https://api.zephyra.dev/api/document/contract/0xContractAddress1/docs" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "tokenId": 123,
    "owner": "0xOwner1",
    "fileHash": "Qmabcdef...",
    "uri": "https://storage.example.com/docs/doc-123.pdf",
    "docType": "Invoice",
    "linkedContracts": ["0xContractAddress1"],
    "status": "Draft",
    "signer": "0xSigner1",
    "createdAt": 1700000000000,
    "updatedAt": 1700000000000,
    "name": "Invoice #123",
    "description": "Invoice for trade #456",
    "metadataUrl": "https://metadata.example.com/doc-123.json",
    "action": "uploaded",
    "txHash": "0xTxHash1"
  }'
```
