# POST `/api/trade/{id}/participant`

Add a participant to a trade.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | yes | Trade ID (path parameter) |

## Request Body

> Content-Type: `application/json`

```json
{
  "address": "0xabc123...",
  "role": "exporter",
  "kycVerified": false,
  "walletConnected": true
}
```

## Responses

### 200 — OK

Participant added successfully, returns updated trade.

```json
{
  "success": true,
  "data": {
    "id": "trade-uuid-123",
    "contractAddress": "0xcontract...",
    "participants": [
      {
        "address": "0x999...",
        "role": "exporter",
        "kycVerified": true,
        "walletConnected": true
      },
      {
        "address": "0xabc123...",
        "role": "importer",
        "kycVerified": false,
        "walletConnected": true
      }
    ],
    "status": "draft",
    "currentStage": 1,
    "createdAt": 1699286400000,
    "updatedAt": 1699372800000
  }
}
```

### 400 — Bad Request

Returned if participant data is missing.

```json
{
  "success": false,
  "message": "Participant data is required"
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the trade with the specified ID does not exist.

```json
{
  "success": false,
  "message": "Trade not found"
}
```

### 422 — Unprocessable Entity

Returned if the `id` path parameter is missing.

```json
{
  "success": false,
  "message": "Missing trade id parameter"
}
```

### 500 — Server Error

Returned if there is a server error while adding the participant.

```json
{
  "success": false,
  "message": "Failed to add participant"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X POST "https://api.zephyra.dev/api/trade/trade-uuid-123/participant" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "0xabc123...",
    "role": "exporter",
    "kycVerified": false,
    "walletConnected": true
  }'
```
