# POST `/api/trade`

Create a new trade.

## Parameters

None.

## Request Body

> Content-Type: `application/json`

```json
{
  "participants": [
    {
      "address": "0x111...",
      "role": "exporter",
      "kycVerified": true,
      "walletConnected": true
    },
    {
      "address": "0x222...",
      "role": "importer",
      "kycVerified": false,
      "walletConnected": false
    }
  ]
}
```

## Responses

### 201 — Created

Trade successfully created.

```json
{
  "success": true,
  "data": {
    "id": "trade-uuid-789",
    "contractAddress": null,
    "participants": [
      {
        "address": "0x111...",
        "role": "exporter",
        "kycVerified": true,
        "walletConnected": true
      }
    ],
    "status": "draft",
    "currentStage": 1,
    "createdAt": 1699286400000,
    "updatedAt": 1699286400000
  }
}
```

### 400 — Bad Request

Returned if the request body fails validation (e.g., missing participants).

```json
{
  "success": false,
  "message": "Participants are required"
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error

Returned if there is a server error while creating the trade.

```json
{
  "success": false,
  "message": "Failed to create trade"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X POST "https://api.zephyra.dev/api/trade" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "participants": [
      {
        "address": "0x111...",
        "role": "exporter",
        "kycVerified": true,
        "walletConnected": true
      },
      {
        "address": "0x222...",
        "role": "importer",
        "kycVerified": false,
        "walletConnected": false
      }
    ]
  }'
```
