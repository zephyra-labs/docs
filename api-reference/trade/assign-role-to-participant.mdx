# PATCH `/api/trade/{id}/role`

Assign or update a participant's role in a trade.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | yes | Trade ID (path parameter) |

## Request Body

> Content-Type: `application/json`

```json
{
  "address": "0xabc123...",
  "role": "importer"
}
```

## Responses

### 200 — OK

Returns the updated list of participants with their roles.

```json
{
  "success": true,
  "data": [
    {
      "address": "0x111...",
      "role": "exporter",
      "kycVerified": true,
      "walletConnected": true
    },
    {
      "address": "0xabc123...",
      "role": "importer",
      "kycVerified": false,
      "walletConnected": true
    }
  ]
}
```

### 400 — Bad Request

Returned if the request body is missing `address` or `role`.

```json
{
  "success": false,
  "message": "Participant address and role are required"
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the trade or participant does not exist.

```json
{
  "success": false,
  "message": "Trade not found"
}
```

### 422 — Unprocessable Entity

Returned if the `id` path parameter is missing.

```json
{
  "success": false,
  "message": "Missing trade id parameter"
}
```

### 500 — Server Error

Returned if there is a server error while assigning the role.

```json
{
  "success": false,
  "message": "Failed to assign role"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X PATCH "https://api.zephyra.dev/api/trade/trade-uuid-123/role" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "0xabc123...",
    "role": "importer"
  }'
```
