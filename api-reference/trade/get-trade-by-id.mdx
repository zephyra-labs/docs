# GET `/api/trade/{id}`

Get a trade by its ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | yes | Trade ID (path parameter) |

## Responses

### 200 — OK

Returns the requested trade record.

```json
{
  "success": true,
  "data": {
    "id": "trade-uuid-123",
    "contractAddress": "0xabc123...",
    "participants": [
      {
        "address": "0x111...",
        "role": "exporter",
        "kycVerified": true,
        "walletConnected": true
      }
    ],
    "status": "draft",
    "currentStage": 1,
    "createdAt": 1699286400000,
    "updatedAt": 1699372800000
  }
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the trade with the specified ID does not exist.

```json
{
  "success": false,
  "message": "Trade not found"
}
```

### 422 — Missing Parameter

Returned if the trade ID is missing.

```json
{
  "success": false,
  "message": "Missing id parameter"
}
```

### 500 — Server Error

Returned if there is a server error while fetching the trade.

```json
{
  "success": false,
  "message": "Failed to fetch trade"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/trade/trade-uuid-123" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```
