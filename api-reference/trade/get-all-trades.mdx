# GET `/api/trade`

Get all trade records. No parameters required.

## Parameters

None.

## Responses

### 200 — OK

Returns a list of trade records.

```json
[
  {
    "success": true,
    "data": {
      "id": "trade-uuid-123",
      "contractAddress": "0xabc123...",
      "participants": [
        {
          "address": "0x111...",
          "role": "exporter",
          "kycVerified": true,
          "walletConnected": true
        }
      ],
      "status": "draft",
      "currentStage": 1,
      "createdAt": 1699286400000,
      "updatedAt": 1699372800000
    }
  }
]
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error

Returned if there is a server error while fetching trades.

```json
{
  "success": false,
  "message": "Failed to fetch trade"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/trade" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```
