# GET `/api/trade/my`

Get trades for the current authenticated user. No parameters required.

## Parameters

None.

## Responses

### 200 — OK

Returns a list of trade records for the authenticated user.

```json
{
  "success": true,
  "data": [
    {
      "id": "trade-uuid-111",
      "contractAddress": "0xcontract1...",
      "participants": [
        {
          "address": "0xUserAddress...",
          "role": "exporter",
          "kycVerified": true,
          "walletConnected": true
        }
      ],
      "status": "inProgress",
      "currentStage": 2,
      "createdAt": 1699286400000,
      "updatedAt": 1699372800000
    },
    {
      "id": "trade-uuid-222",
      "contractAddress": "0xcontract2...",
      "participants": [
        {
          "address": "0xUserAddress...",
          "role": "importer",
          "kycVerified": true,
          "walletConnected": true
        }
      ],
      "status": "draft",
      "currentStage": 1,
      "createdAt": 1699200000000,
      "updatedAt": 1699203600000
    }
  ]
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the user has no trades.

```json
{
  "success": false,
  "message": "No trades found for user"
}
```

### 500 — Server Error

Returned if there is a server error while fetching trades.

```json
{
  "success": false,
  "message": "Failed to fetch user trades"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/trade/my" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```
