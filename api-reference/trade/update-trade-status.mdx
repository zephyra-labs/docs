# PATCH `/api/trade/{id}/status`

Update the status of a trade.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | yes | Trade ID (path parameter) |

## Request Body

> Content-Type: `application/json`

```json
{
  "status": "completed"
}
```

## Responses

### 200 — OK

Returns the updated trade record with the new status.

```json
{
  "success": true,
  "data": {
    "id": "trade-uuid-123",
    "contractAddress": "0xabc123...",
    "participants": [
      {
        "address": "0x111...",
        "role": "exporter",
        "kycVerified": true,
        "walletConnected": true
      }
    ],
    "status": "completed",
    "currentStage": 3,
    "createdAt": 1699286400000,
    "updatedAt": 1699372800000
  }
}
```

### 400 — Bad Request

Returned if the status value is missing or invalid.

```json
{
  "success": false,
  "message": "Status is required"
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the trade does not exist.

```json
{
  "success": false,
  "message": "Trade not found"
}
```

### 422 — Unprocessable Entity

Returned if the `id` path parameter is missing.

```json
{
  "success": false,
  "message": "Missing trade id parameter"
}
```

### 500 — Server Error

Returned if there is a server error while updating the status.

```json
{
  "success": false,
  "message": "Failed to update trade status"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X PATCH "https://api.zephyra.dev/api/trade/trade-uuid-123/status" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "completed"
  }'
```
