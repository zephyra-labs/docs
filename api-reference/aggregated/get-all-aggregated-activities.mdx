# GET `/api/aggregated`

Fetch all aggregated activity logs recorded in the system. Supports optional query parameters for filtering and pagination.

## Query Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `account` | `string` | No | Filter by wallet account |
| `txHash` | `string` | No | Filter by transaction hash |
| `contractAddress` | `string` | No | Filter by smart contract address |
| `tags` | `string` | No | Filter by tags (comma-separated) |
| `limit` | `integer` | No | Maximum number of items to return |
| `startAfterTimestamp` | `integer` | No | Pagination cursor (start after this timestamp in ms) |

## Responses

### 200 — OK  

Returned when aggregated activities are successfully fetched, with optional filtering and pagination applied.

### 400 — Bad Request  

Returned when a query parameter contains an invalid type (e.g., `limit` or `startAfterTimestamp` is not a number).

```json
{
  "success": false,
  "message": "limit must be a number"
}
```

### 401 — Unauthorized  

Returned when the request does not include a valid Bearer token in the Authorization header.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error  

Returned when the server encounters an unexpected error while fetching aggregated activities.

```json
{
  "success": false,
  "message": "Failed to fetch aggregated activities"
}
```

## Authentication

This endpoint requires a **Bearer Token**.  
Admin privileges may be required to fetch aggregated system-wide activity logs.

## Notes

* `nextStartAfterTimestamp` is used for cursor-based pagination to retrieve the next batch.  
* Filters `account`, `txHash`, `contractAddress`, and `tags` are optional.  
* `tags` should be passed as a comma-separated string, such as `user,signup`.  
* If no filters are provided, the endpoint returns all aggregated activities.

## Example Request (cURL)

```bash
curl -X GET "https://api.zephyra.dev/api/aggregated?account=0xABC123&limit=10" \
  -H "Authorization: Bearer <token>"
```
