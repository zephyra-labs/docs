# POST `/api/aggregated/{id}/tag`

Add a tag to an existing aggregated activity log.

## Path Parameters

| Name | Type   | Required | Description                  |
|------|--------|----------|------------------------------|
| `id` | `string` | yes      | Aggregated activity ID       |

## Request Body

| Field | Type   | Required | Description       |
|-------|--------|----------|------------------|
| `tag` | `string` | yes      | Tag to add       |

### Example Request Body

```json
{
  "tag": "smart-contract"
}
```

## Responses

### 200 — OK  

Returned when the tag is successfully added to the aggregated activity.

```json
{
  "success": true,
  "data": {
    "tag": "smart-contract",
    "message": "Tag added successfully"
  }
}
```

### 400 — Bad Request  

Returned when required fields are missing or invalid, or the `id` parameter is missing.

```json
{
  "success": false,
  "message": "Tag is required and must be a string"
}
```

```json
{
  "success": false,
  "message": "Missing ID parameter"
}
```

### 401 — Unauthorized  

Returned when the request is missing a valid authorization token.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found  

Returned when the aggregated activity ID does not exist.

```json
{
  "success": false,
  "message": "Aggregated activity log not found"
}
```

### 500 — Server Error  

Returned when the system fails to add the tag due to a server-side issue.

```json
{
  "success": false,
  "message": "Failed to add tag to aggregated activity"
}
```

## Authentication

This endpoint requires a **Bearer Token**.  
Admin privileges may be required to add tags.

## Example Request (cURL)

```bash
curl -X POST "https://api.zephyra.dev/api/aggregated/agg-001/tag" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "tag": "smart-contract"
  }'
```

## Example Response

```json
{
  "success": true,
  "data": {
    "tag": "smart-contract",
    "message": "Tag added successfully"
  }
}
