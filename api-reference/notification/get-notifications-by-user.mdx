# GET `/api/notification/user/{userId}`

Get notifications for a specific user.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `userId` | `string` | yes | User ID (path parameter) |

## Responses

### 200 — OK

Returns a list of notifications for the specified user.

```json
[
  {
    "id": "notif-uuid-123",
    "userId": "user-uuid-456",
    "executorId": "user-uuid-789",
    "type": "kyc",
    "title": "KYC Approved",
    "message": "Your KYC request has been approved.",
    "read": false,
    "createdAt": 1699286400000,
    "updatedAt": 1699372800000,
    "extraData": {
      "kycId": "kyc-uuid-123"
    }
  },
  {
    "id": "notif-uuid-124",
    "userId": "user-uuid-456",
    "executorId": "system",
    "type": "system",
    "title": "System Update",
    "message": "Maintenance scheduled at 2 AM.",
    "read": true,
    "createdAt": 1699380000000,
    "updatedAt": 1699383600000,
    "extraData": {}
  }
]
```

### 400 — Bad Request

Returned if the `userId` parameter is missing.

```json
{
  "success": false,
  "message": "Missing userId parameter"
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the user does not exist or has no notifications.

```json
{
  "success": false,
  "message": "No notifications found for this user"
}
```

### 500 — Server Error

Returned if there is a server error while fetching user notifications.

```json
{
  "success": false,
  "message": "Failed to fetch user notifications"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/notification/user/user-uuid-456" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```
