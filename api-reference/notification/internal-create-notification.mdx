# POST `/api/notification/internal`

Create a new notification internally for system purposes.

## Parameters

None.

## Request Body

> Content-Type: `application/json`

```json
{
  "userId": "user-uuid-456",
  "executorId": "user-uuid-789",
  "type": "system",
  "title": "New Trade Completed",
  "message": "Your trade #123 has been completed successfully.",
  "extraData": {
    "tradeId": "trade-uuid-987"
  }
}
```

## Responses

### 201 — Created

Notification successfully created.

```json
{
  "id": "notif-uuid-123",
  "userId": "user-uuid-456",
  "executorId": "user-uuid-789",
  "type": "system",
  "title": "New Trade Completed",
  "message": "Your trade #123 has been completed successfully.",
  "read": false,
  "createdAt": 1699286400000,
  "updatedAt": 1699372800000,
  "extraData": {
    "tradeId": "trade-uuid-987"
  }
}
```

### 400 — Bad Request

Returned if required fields are missing.

```json
{
  "success": false,
  "message": "Missing required fields"
}
```

### 401 — Unauthorized

Returned if internal authentication fails.

```json
{
  "success": false,
  "message": "Internal authentication failed"
}
```

### 500 — Server Error

Returned if there is a server error while creating the notification.

```json
{
  "success": false,
  "message": "Failed to create notification"
}
```

## Authentication

This endpoint requires **Internal Bearer Token** authentication.

## Example Request

```bash
curl -X POST "https://api.zephyra.dev/api/notification/internal" \
  -H "Authorization: Bearer <internal-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "user-uuid-456",
    "executorId": "user-uuid-789",
    "type": "system",
    "title": "New Trade Completed",
    "message": "Your trade #123 has been completed successfully.",
    "extraData": {
      "tradeId": "trade-uuid-987"
    }
  }'
```
