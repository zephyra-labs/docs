# DELETE `/api/notification/{id}`

Delete a notification.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | yes | Notification ID (path parameter) |

## Responses

### 200 — OK

Notification deleted successfully.

```json
{
  "message": "Notification deleted successfully"
}
```

### 400 — Bad Request

Returned if the `id` parameter is missing.

```json
{
  "success": false,
  "message": "Missing id parameter"
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the notification with the specified ID does not exist.

```json
{
  "success": false,
  "message": "Notification not found"
}
```

### 500 — Server Error

Returned if there is a server error while deleting the notification.

```json
{
  "success": false,
  "message": "Failed to delete notification"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X DELETE "https://api.zephyra.dev/api/notification/notif-uuid-123" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```

## Example Response

```json
{
  "message": "Notification deleted successfully"
}
```
