# PATCH `/api/notification/{id}/read`

Mark a notification as read.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | yes | Notification ID (path parameter) |

## Responses

### 200 — OK

Notification marked as read successfully.

```json
{
  "message": "Notification marked as read"
}
```

### 400 — Bad Request

Returned if the `id` parameter is missing.

```json
{
  "success": false,
  "message": "Missing id parameter"
}
```

### 401 — Unauthorized

Returned if the user is not authenticated.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 404 — Not Found

Returned if the notification with the specified ID does not exist.

```json
{
  "success": false,
  "message": "Notification not found"
}
```

### 500 — Server Error

Returned if there is a server error while marking the notification as read.

```json
{
  "success": false,
  "message": "Failed to mark notification as read"
}
```

## Authentication

This endpoint requires a **Bearer Token**.

## Example Request

```bash
curl -X PATCH "https://api.zephyra.dev/api/notification/notif-uuid-123/read" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json"
```

## Example Response

```json
{
  "message": "Notification marked as read"
}
```
