# GET `/api/activity`

Fetch all activity logs recorded in the system. Supports optional query filters for account, transaction hash, and pagination.

## Query Parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| `account` | `string` | No | Filter results by account address |
| `txHash` | `string` | No | Filter results by transaction hash |
| `limit` | `integer` | No | Maximum number of results to return (minimum 1) |
| `startAfterTimestamp` | `integer` | No | Return results after this Unix timestamp (ms) — used for pagination |

### 400 — Bad Request  

Returned when query parameters contain invalid types.

```json
{
  "success": false,
  "message": "limit must be a number"
}
```

```json
{
  "success": false,
  "message": "startAfterTimestamp must be a number"
}
```

### 401 — Unauthorized  

Returned when the Authorization header is missing or invalid.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error  

Returned when the server fails to fetch or process activity logs.

```json
{
  "success": false,
  "message": "Failed to fetch activities"
}
```

## Authentication

This endpoint requires authentication using a **Bearer Token**.

## Notes
* `limit` defaults to a server-defined value if not provided.  
* `startAfterTimestamp` supports cursor-based pagination.  
* `account` and `txHash` may be used together.  
* `onChainInfo` only appears for `onChain` activities.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/activity?account=0xabc123&limit=10" \
  -H "Authorization: Bearer <token>"
```
