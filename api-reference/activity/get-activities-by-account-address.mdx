# GET `/api/activity/{account}`

Fetch all activity logs for a given wallet address. Supports pagination through query parameters.

## Path Parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| `account` | `string` | Yes | Wallet address used to filter activity logs |

## Query Parameters
| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `integer` | No | Maximum number of results to return (minimum 1) |
| `startAfterTimestamp` | `integer` | No | Return results after this Unix timestamp (ms) — used for pagination |

### 400 — Bad Request  

Returned if required parameters are missing or query parameter types are invalid.

```json

```


```json
{

  "message": "startAfterTimestamp must be a number"
}
```

### 401 — Unauthorized  

Returned when the Authorization header is missing or invalid.

```json
{
  "success": false,
  "message": "Missing or invalid Authorization header"
}
```

### 500 — Server Error  

Returned when an internal error occurs while reading activity logs.

```json
{
  "success": false,
  "message": "Failed to fetch activities for this account"
}
```

## Authentication

This endpoint requires authentication using a **Bearer Token**.

## Notes
* `limit` defaults to a server-defined value if not provided.  
* `startAfterTimestamp` supports cursor-based pagination.  
* Only activities for the specified `account` are returned.  
* `onChainInfo` appears only for `onChain` activities.

## Example Request

```bash
curl -X GET "https://api.zephyra.dev/api/activity/0xabc123?limit=10" \
  -H "Authorization: Bearer <token>"
```
